Do / Don't

디자인 시스템의 핵심 원칙

Do

  • Shadow로 깊이 표현
  • SVG inline 아이콘 사용
  • transition: background 0.2s
  • tabular-nums (동적 숫자)
  • text-wrap: balance (제목)
  • 40×40px 이상 터치 영역
  • 페이지별 고유 색상
  • Fraunces = Display only
  • 그라디언트 = Hero 카드에만

Don't

  • Border로 카드 구분
  • 유니코드 기호 (●○×▾‹›)
  • transition: all 0.2s
  • 기본 proportional 숫자
  • 수동 \n 줄바꿈
  • 작은 터치 타겟
  • 모든 페이지 동일한 흰색
  • Fraunces로 본문 작성
  • 모든 요소에 그라디언트
